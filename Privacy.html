Politique de Confidentialité

Dernière mise à jour : 11 mars 2026

La protection de vos données est une priorité. Cette page vous explique quelles informations sont collectées et comment elles sont utilisées dans l'application Homepage360.

1. Collecte des données

Nous collectons les types d'informations suivants :

  • Données de localisation : Si vous l'autorisez, l'application utilise votre position pour fournir des prévisions météo locales précises via nos partenaires (OpenWeather/Open-Meteo).
  • Données d'achat : Pour le mode Premium, les transactions sont gérées exclusivement par le Google Play Store. Nous n'avons jamais accès à vos coordonnées bancaires.
  • Données techniques : Des informations anonymes (modèle du téléphone, version d'Android) peuvent être traitées pour corriger des bugs.

2. Utilisation des données

Vos données sont utilisées uniquement pour :

  • Fournir le service de prévision météo.
  • Valider votre abonnement ou achat Premium.
  • Améliorer la stabilité de l'application.

3. Services tiers

L'application utilise des services tiers qui peuvent collecter des données conformément à leurs propres politiques :

  • Google Play Services (Gestion de l'application et des achats).
  • [OpenWeather / Open-Meteo] (Fournisseur de données météo).
  • GitHub (Hébergement du flux de configuration).

4. Vos droits (RGPD)

Conformément au RGPD, vous disposez d'un droit d'accès, de modification et de suppression de vos données. Pour toute demande, contactez-nous par e-mail.
